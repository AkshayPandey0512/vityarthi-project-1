# 🔥 Personal Habit Tracker

A powerful, intuitive habit-tracking application built with Python to help you build lasting positive habits through consistent tracking and motivational analytics.

![License](https://img.shields.io/badge/License-MIT-green.svg)
![Code Size](https://img.shields.io/badge/Code%20Size-180%20lines-orange.svg)

## ✨ Features

### 🎯 Core Tracking
- **Habit Management** - Add, view, and delete habits
- **Daily Completion** - Mark habits as complete each day
- **Streak Tracking** - Automatic current and longest streak calculation
- **Multiple Categories** - Organize by Health, Productivity, Learning, etc.

### 📊 Analytics & Insights
- **Weekly Reports** - Visual progress bars and completion rates
- **Category Statistics** - Performance analysis by habit type
- **Streak Analytics** - Average and best streak tracking
- **Progress Visualization** - ASCII charts and emoji feedback

### 🔧 Technical Features
- **Local Data Storage** - JSON-based persistence
- **No Dependencies** - Pure Python, no installations required
- **Cross-Platform** - Works on Windows, macOS, and Linux
- **Privacy-Focused** - All data stored locally on your machine
